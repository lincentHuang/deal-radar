## 🏷️ 三、 標籤系統體系與訂閱機制 (Tag Governance & Subscriptions)

```
┌─────────────────────────────────────────────────────────────┐
│ 頂部副 Header (SubHeaderTagNav):                             │
│ [ All 全部 ]  [ 🌟 我的標籤 ]  [ #咖啡 ]  [ #買一送一 ]  [ 🔥 探索推薦 ] │
└─────────────────────────────────────────────────────────────┘
```

### 3.1 標籤新增 / 訂閱的 2 大標準渠道
1. **渠道一：首頁推薦標籤彈窗（🔥 探索推薦）**：
   - 點擊副 Header 右側「🔥 探索推薦」，開啟官方分類推薦標籤池（促銷、咖啡、超市量販、電商 3C、信用卡）。
   - 點擊「＋ 訂閱」或「✓ 已訂閱」即可即時加入/移除個人上方副 Header 標籤列。
2. **渠道二：搜尋與標籤專屬頁面 (`/tag/[tagName]`)**：
   - 搜尋或瀏覽特定標籤時，頂部專屬 Header 顯示「⭐ 訂閱此標籤」按鈕，一鍵追蹤加入頂部標籤列。

### 3.2 副 Header 標籤列排序與行為規範
* **第 1 項：All 全部**（`selectedTag: null`）➔ 瀏覽全站最新特價。
* **第 2 項：🌟 我的標籤**（`selectedTag: '__MY_TAGS__'`）➔ 聚合呈現使用者已訂閱的所有標籤對應的情報。若未訂閱，引導探索推薦。
* **第 3 項起：已訂閱的個別標籤**（如 `#咖啡`、`#買一送一` 等）➔ 點擊只篩選單一標籤。
* **右側常駐按鈕：🔥 探索推薦** ➔ 彈出官方推薦詞庫庫進行快速訂閱。

### 3.3 會員個人中心頁面 (`/profile`)
* **會員名片**：顯示 VIP 身份、已訂閱標籤數、收藏數、預估省下金額。
* **訂閱標籤集中管理**：查看全部已訂閱標籤、一鍵刪除/取消訂閱、一鍵重置熱門標籤。
* **推薦標籤探索池**：分類瀏覽各維度推薦標籤並支援快速開關訂閱。

## 📋 五、 驗收標準 (AC)

### 5.1 AC-01: 大圖呈現與視覺收斂
* **Given** 使用者進入首頁瀑布流。
* **When** 情報卡片渲染完成。
* **Then** 每張卡片均需展示高品質封面大圖，且文字資訊收斂不雜亂，以 🎯 條件 Icon 與 💳 信用卡 Icon 取代長串文字。

### 5.2 AC-02: 彈窗展開完整 7 大要素
* **Given** 使用者點擊任一精簡情報卡片。
* **When** 詳情彈窗開啟。
* **Then** 彈窗需完整展示 7 大要素（品項細節、所有條件清單、信用卡回饋、歷史比價走勢圖與核銷條碼）。

### 5.3 AC-03: 副 Header 標籤導覽順序與「我的標籤」聚合
* **Given** 使用者位於任何頁面瀏覽副 Header。
* **When** 查看標籤橫向滑動列。
* **Then** 第 1 項固定為 `All 全部`，第 2 項固定為 `🌟 我的標籤`，第 3 項起為個人已訂閱標籤；點擊 `🌟 我的標籤` 需聚合顯示所有已訂閱標籤的特價情報。

### 5.4 AC-04: 標籤訂閱雙渠道驗證
* **Given** 使用者點擊「🔥 探索推薦」或位於搜尋/標籤專屬頁面。
* **When** 點擊「＋ 訂閱」或「⭐ 訂閱此標籤」。
* **Then** 系統需觸發觸覺反饋與慶祝動效，並立即將該標籤常駐至首頁頂部副 Header 標籤列。

### 5.5 AC-05: 個人中心頁面管理 (`/profile`)
* **Given** 使用者進入 `/profile`。
* **When** 進行已訂閱標籤的刪除或新增推薦標籤。
* **Then** 全站狀態即時同步更新，首頁副 Header 標籤列同步反應變更。

### 5.6 AC-07: 優惠詳情來源連結導航與開發者查驗
* **Given** 使用者或開發者點開任一特價情報卡片開啟 `DealDetailModal`。
* **When** 檢視彈窗內的「情報來源與查驗連結」區塊或底部操作列。
* **Then**：
  1. 彈窗內清楚呈現管道來源（如 7-11 粉專 / 全家粉專 / Dcard / Momo 等）與社群互動數據。
  2. 點擊「複製網址」按鈕能一鍵複製完整 `sourceUrl` 並反饋「已複製」狀態。
  3. 點擊「開啟來源」或底部「前往官方貼文 / 來源頁」按鈕，能在新分頁快速開啟對應原始連結。
  4. 實體門市特惠同時保留「現場出示兌換 (QR Code)」與「前往官方貼文」雙功能。

### 5.7 AC-08: 優惠詳情高畫質大圖展示、Lightbox 放大與關聯標籤互動雲
* **Given** 使用者點擊情報卡片展開 `DealDetailModal`。
* **When** 檢視彈窗內容。
* **Then**：
  1. 彈窗頂部以大尺寸高畫質展示促銷主圖（`aspect-[4/3]` 或 `16/10` 自適應），並保留折扣/快閃浮動徽章。
  2. 具備多張圖卡時，支援下方縮圖即時切換。
  3. 點擊主圖或「查看大圖」按鈕，能喚起全螢幕 Lightbox 燈箱放大檢視海報細節與價目表。
  4. 內容區完整列出該促銷所有關聯標籤（`#買一送一`、`#7-ELEVEN`、`#國泰CUBE` 等），支援單鍵切換追蹤狀態與外連直達專屬標籤頁。
