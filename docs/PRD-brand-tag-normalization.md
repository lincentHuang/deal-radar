## 🎯 一、背景與問題陳述 (Problem Statement)

目前特價情報站從多個渠道（Facebook 官方粉絲專頁、食尚玩家美食報導、品牌官網活動頁、店家自主發布）自動採集特價資訊。然而在實務上：
1. **品牌名稱多樣紛歧**：同一個通路在不同來源有諸多不同寫法，例如 `全家`、`familyMart`、`FamilyMart`、`全家便利商店`、`全家 FamilyMart`；`7-ELEVEN`、`7-11`、`711`、`統一超商`；`家樂福`、`Carrefour` 等。
2. **標籤冗長佔用空間**：卡片上若出現 `#全家FamilyMart`、`#全家便利商店` 等長標籤，在手機端會造成標籤欄換行擁擠、破壞排版美觀。
3. **特定品牌更名需求**：依據最新業務規則，原 `家樂福 / Carrefour` 全面統整更名為 **`萬家福`**（標籤為 `#萬家福`）。

---

## 💡 二、產品目標與解決方案 (Goals & Solutions)

建立中央「**品牌與標籤精簡標準化引擎 (Brand Normalizer Engine)**」：
1. **最短空間原則**：所有品牌標籤自動收斂為「最簡短、高辨識度」之中文名稱（如 `#全家`、`#7-11`、`#全聯`、`#萬家福`、`#麥當勞`）。
2. **多管道全自動歸類**：
   - 爬蟲資料提取（AI Vision 多模態與正則切片）時立即標準化。
   - 資料庫寫入（DAL Upsert、Create、Batch Edit）前二次校驗，防止髒資料入庫。
   - 歷史資料庫一次性清洗，將現有所有情報的品牌與標籤切換至最新規範。
3. **標籤自動去重與清理**：
   - 自動將 `#` 開頭補齊。
   - 若已有標準化品牌標籤（如 `#全家`），自動剔除其餘同品牌的長英文/別名標籤（如 `#FamilyMart`、`#全家便利商店`）。
   - 保留促銷機制標籤（如 `#買一送一`、`#第二件5折`）與品類標籤（如 `#咖啡`、`#霜淇淋`）。

## 🛡️ 四、驗收標準 (Acceptance Criteria, AC)

- [x] **AC-1 (品牌與標籤正規化)**：所有已知別名輸入 `normalizeBrandName` 與 `normalizeTags` 後，100% 輸出為最短標準名稱與 `#簡短Tag`。
- [x] **AC-2 (更名規則精確轉換)**：`家樂福`、`Carrefour` 及其相關組合字樣 100% 轉換為 `萬家福` 與 `#萬家福`。
- [x] **AC-3 (標籤去重與空間極小化)**：若輸入含有多個同義詞標籤（如 `['#全家FamilyMart', '#全家便利商店', '#familyMart', '#霜淇淋']`），自動過濾收斂為 `['#全家', '#霜淇淋']`。
- [x] **AC-4 (端到端管道生效)**：爬蟲（FB/Web/Blog）、AI 解析器、DAL 儲存、自建發布均自動經過標準化。
- [x] **AC-5 (現有資料洗滌完成)**：現存資料庫內所有舊情報皆已成功批次轉換。
